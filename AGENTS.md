# Tali page project rules

## Scope

- Static bilingual landing page in Russian and Hebrew.
- Keep the project independent from WordPress and other sites.
- Do not publish or connect a domain without explicit approval.

## Content

- Russian copy may use “логопедическая работа”.
- Hebrew copy uses development-oriented wording and does not claim a regulated professional title.
- Do not invent education, experience, licences, testimonials, results, address or contact details.
- Do not make medical promises or present the page as a substitute for diagnosis.

## Structure

- Edit identity, photo and form settings in `assets/js/config.js`.
- Edit translations in `assets/js/content.js`.
- Edit the colour scheme in `assets/css/theme.css`.
- Keep responsive layout rules in `assets/css/site.css`.
- Never put bot tokens or SMTP credentials in browser files.

## Verification

- Check JavaScript syntax.
- Check Russian LTR and Hebrew RTL.
- Check desktop, tablet and 390 px mobile widths.
- Check navigation, language switching, accordion and form validation.
- Verify that the page has no horizontal overflow.
